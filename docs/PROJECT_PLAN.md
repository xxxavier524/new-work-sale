# 跨境电商项目主计划：澳洲双类目主线 + 俄罗斯备线

> **文件用途**：本文件是与 Claude Code 协作的项目单一事实来源（Single Source of Truth）。
> **数据核实日期**：2026-07-04。所有标 ⚠ 的项目在执行对应动作前**必须重新核实**。
> **操作者画像**：个人兼职（每周 ≤12h），启动预算 ¥60,000（下限 ¥40,000），有编程能力（Mac mini M4），可用 AI 全流程辅助。
> **纪律三条**（不可协商）：① 毛利红线 55% 以下不上架；② 一期负面清单禁碰；③ G3 止损线无条件执行。

## 0. 项目一句话

把中国产业带供给（广州汽配软装 + 威海渔具）卖给澳洲「4WD × 钓鱼」重叠人群；中国直发起步、零海外仓；渔具做复购现金流，4WD 软装做高客单利润池；俄罗斯 Ozon 作为政策对冲备线。

## 2. 战略架构

- **法人**：一人有限责任公司（非个体户）。原因：Ozon 要求中国大陆或香港**公司**营业执照、不支持个体户；一个主体通吃主线+备线。代账成本约 ¥2–3k/年。
- **主线渠道**：eBay AU 起步 →（验证后）Amazon AU → Shopify 独立站（GEO 承接）。
- **收款**：Payoneer / 万里汇。⚠ eBay AU 中国卖家 CBT 入驻细则以注册当日官方页面为准。
- **人群逻辑**：拖着船去钓点的越野人群 = 一套内容矩阵，双类目变现。
- **备线触发条件**（满足其一）：主线 G3 未过且复盘无可修因子；或主线 M5 稳定后作为第二增长线。
- **商标**：AU 商标 1 类先行（约 A$250/类），为 Amazon Brand Registry 和防跟卖铺路；马德里体系二期再议。

## 3. 产品定义（第一批）

### SKU-A｜Hilux/Ranger 座椅背 MOLLE 收纳系统（帆布）
- **定位**：Adventure Kings 之上、ARB 之下的「金属五金层」。
- **规格**（逐条对应差评痛点）：900D 面料并标注克重；**全金属扣具**（不接受工厂默认塑料件）；YKK 拉链；双针加固、针距 ≤3mm；车型专用剪裁（首发 Hilux N80 / Ranger 后排）；宣称只写 water-resistant 不写 waterproof。
- **定价**：A$49.95。**Listing 首行**："Metal hardware. No plastic clips."
- **工厂询价要点**：扣具供应商指定；首批 150 件；返单价写入 PI；批检 10% 抽测扣具与缝线。
- **供应链**：广州（汽配软装/帆布缝纫带）。

### SKU-B｜Squid 入门系统套装（5 只校准木虾 + 排水收纳包）
- **定位**：避开本土品牌 Rui（A$11.99 单只已占中间档）的单只战场，卖「开箱即钓的系统」。
- **规格**：2.5/3.0/3.5 混号；**不锈钢伞钩**；锡制配重（不用铅）；UV + 夜光布面；**每批出厂泡水校准 45° 沉姿并在包装标注实测沉速**（对标 Yamashita：2.5 号 10.5g/5.0s·m⁻¹、3.0 号 15g/3.5s、3.5 号 20g/3.0s）；wallet 网眼排水 + 钩冠 EVA 护套。
- **定价**：A$39.95（对标：5 只 Yamashita 约 A$80+；5 只 $2 垃圾档会锈会散架）。
- **工厂询价要点**：威海找**有对日出口记录**的厂（日单 = 沉速品控已过关），索要对日报关单；swim-test 写入质检单。

### 一期负面清单（铁律，任何 SKU 不得触碰）
承重救援装备（软卸扣/动能绳/拖车带）｜任何带电/锂电产品｜刀刃类｜铅制钓坠 ⚠（部分州环保争议）｜车灯（ADR 道路法规）｜头盔护具（强制认证）。
剩余的帆布、塑料、硅胶、金属小件为自由射击区。

## 4. 痛点研究档案（已完成，2026-07-04）

### 4.1 4WD 软装（来源：ProductReview.com.au / Trustpilot 上 Adventure Kings 评价库）
- **C1 五金件是死穴（最高频）**：塑料夹扣首次使用即断裂，买家自行更换更结实扣件。→ 差异化：金属扣具 + YKK，成本 +¥3–5。
- **C2 面料与防水虚标**：swag 面料偏薄、小雨渗湿。→ 标克重、只宣称 water-resistant、拍缝线视频验证。
- **C3 电器类是差评核爆区**：启动电源、发电机、冰箱大量一星。→ 印证「非电类」进入点，差评密度最低。
- **C4 售后是 Kings 裸露侧翼**：换货收 10% 重新上架费、保修推诿、配送商 96% 差评。→ 本店政策：小件直接补发不要求退回（补发成本 < 争议成本 < 差评成本）。
- **C5 QA 批次不稳**：同型号体验两极。→ 批检 SOP 写入 PI。

### 4.2 木虾（来源：澳洲钓鱼论坛 enoughgun / AKFF、FishingMad 评测、零售商指南）
- **J1 锈与散架**：$2 档「rusted to bits」，Yamashita 多年不锈。→ 不锈钢伞钩是生死线。
- **J2 沉降姿态是功能命门**：便宜 jig 直坠如石，钓友自己剪配重修正，「屁股先沉的直接扔」。→ 核心差异化 = 逐批泡水校准 + 标注沉速（边际成本极低，中低价位无人做）。
- **J3 歪游与旋转**：拖环弯曲 → 下沉旋转缠线杀死咬口。→ swim-test 入质检单。
- **J4 收纳是无人认领的真痛点**：湿 jig 带盐入包、钩冠互缠、盐分腐蚀、布面发臭，现有软包不透气。→ 排水透气 wallet = 配件空白，纯纺织零认证风险。
- **竞争事实**：Yamashita A$16–20/只锚定高端；本土线上品牌 Rui 以 A$11.99 + 本地配色 + 48h 达占据中间档。→ 结论：不做单只对轰，做系统套装。

## 5. 单位经济模型（供 Claude Code 构建计算器，见 T1）

### 5.1 基准参数（config，全部可调）
```yaml
fx_aud_cny: 4.7          # ⚠ 以实时汇率为准，季度复核定价
channel_fee_rate: 0.19    # eBay FVF≈13.4% + 推广位≈5% 综合
shipping_cny_per_kg: 45   # 专线双清区间 40–55，时效 7–15 天
returns_provision: 0.05   # 退货拨备，触发 8% 即报警（见 G3）
gross_margin_floor: 0.55  # 建模毛利红线，低于此值不上架
fixed_cost_monthly: 900   # 工具订阅 + 代账摊销（CNY）
```

### 5.2 首批 SKU 测算（CNY）

| 项目 | SKU-A MOLLE 收纳 | SKU-B 木虾套装 |
|---|---|---|
| 售价 | A$49.95 ≈ ¥235 | A$26.95 ≈ ¥127（套装升级后 A$39.95 ≈ ¥188 待重算）|
| 采购 | 38 | 28（套装含 wallet 约 45 待询价）|
| 运费 | 40（0.8kg） | 16（0.25kg）|
| 渠道费 19% | 45 | 24 |
| 包材杂项 | 7 | 4 |
| **单件净贡献** | **≈105（45%）** | **≈55（43%）** |
| 退货拨备 5% 后 | ≈40% | ≈38% |

- **盈亏平衡**：固定成本 ¥900/月 ÷ 单均净贡献 ≈¥70 → **约 13 单/月保本**。
- **敏感性**（混合净率基准 ~42%）：AUD 贬 10% → ~33%；运费 +30% → ~37%；退货 5%→12% → ~35%；**三重叠加 → 约 18–20%，仍为正**。这就是 55% 毛利红线存在的原因。
- **目标路径**：M3 达 50 单/月 → M4 达 120 单、净利 ¥3k+ → M6 达 250 单、净利 ¥8–10k。

## 8. 风险登记册 + 模型失效条款

| 风险 | 概率 | 冲击 | 对策 / 止损 |
|---|---|---|---|
| eBay 账号审核/受限 | 中 | 高 | 资料真实一致、单店经营；被卡 → Amazon AU + 独立站 |
| 澳洲跟进全球取消免税 | 低–中 | 高 | 季度政策复查（T7）；触发 → 海外仓化或切换俄线 |
| 专线涨价/查验 | 中 | 中 | 双物流商并行报价 |
| 汇率 | 中 | 中 | Payoneer 择机结汇；定价季度复核 |
| 外观专利跟卖投诉 | 低 | 高 | 每 SKU 上架前查 IP Australia 外观库 |
| 兼职精力断档 | 中 | 高 | SOP + AI 自动化；周上限 12h 是设计约束 |
| 竞品价格战 | 中 | 中 | 内容壁垒 + 车型专用，不跟价 |

**模型失效条款（诚实条款）**：
1. 澳洲若取消 A$1,000 免税 → 直发经济性崩塌，主线必须重估（本方案最大单点依赖）。
2. 周投入长期 <8h → 砍成单类目渔具线。
3. 连续两月现金流为负且库存周转 >60 天 → 无条件清仓。

## 9. Claude Code 任务清单（按优先级）

- **T1 落地成本计算器**：输入采购价/重量/售价/参数 config（§5.1）→ 输出净利率、保本单量、敏感性表。验收：三重悲观情形一键复算；参数改动即时生效。
- **T2 差评挖掘 pipeline**：输入评论文本 CSV（或 URL 列表，⚠ 注意目标站 robots/ToS，优先手动导出+本地分析）→ LLM 聚类输出痛点榜单（频次×severity）。验收：对 §4 的人工聚类结果可复现。
- **T3 Listing 生成器**：输入痛点榜 + SKU 规格 → 输出英文标题/五点/描述 3 变体（AB 测试用）。验收：每条卖点可溯源到具体痛点编号。
- **T4 GEO 落地页**：Shopify/静态页模板 + Product schema JSON-LD + 「X vs Kings」对比页。验收：Rich Results 测试通过；页面可被 AI 购物助手解析出价格/规格/库存。
- **T5 客服 SOP + 模板库**：英文；含「小件直接补发不退回」政策话术、物流查询、尺寸适配 FAQ。验收：覆盖 top10 咨询场景，90% 可模板化回复。
- **T6 周报 dashboard**：CSV 输入（订单/退货/广告费）→ 单量、退货率、净利、库存周转天数、G3/G4 距离。验收：每周一 10 分钟内完成复盘。
- **T7 政策监控清单**：季度复查项 + 信息源 URL（见附录）→ 生成复查 checklist。验收：含澳洲免税、汇率、专线价、俄 VAT 四项硬指标。
- **T8（备线）EAC 避雷清单 + Ozon 入驻材料清单**：按品类整理认证要求，标注工具类目风险位。
- **T9 达人外联 CRM**：30 人名单模板（频道/粉丝量/联系方式/寄样状态/内容上线日）+ 首封邮件模板。验收：跟进状态一屏可见。
