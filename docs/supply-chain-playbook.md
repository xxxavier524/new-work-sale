# 供应链执行手册：询价 → 验厂 → PI → 样测 → 批检

> 对应 PROJECT_PLAN §3 工厂询价要点 / §6 D0–30（G2 闸门前的全部纸面工作）。
> 核心纪律：**返单价写入 PI**（防爆单涨价）；**验厂三件套**（防贸易商冒充）；样测不过关不下首批单。

## 1. 询价消息模板（1688/微信直接发）

### SKU-A｜广州汽配软装厂（帆布缝纫带）

```
老板您好，我做澳洲跨境电商，找长期代工厂（非一次性单）。

产品：皮卡座椅背 MOLLE 收纳板（丰田 Hilux / 福特 Ranger 后排专用剪裁）
规格要求（请逐条确认能否做到）：
1. 900D 面料，请报克重并在标签标注
2. 扣具全金属——塑料件不接受；扣具供应商由我方指定或从你们的金属件供应商中选定
3. 拉链用 YKK（请报 YKK 与国产替代的差价）
4. 双针加固，针距 ≤3mm
5. 车型专用版型（我方提供尺寸图），非通用款

请报：
- 打样费用与周期（要 2–3 个样）
- 首批 150 件单价（含包装）
- 返单 300 件 / 500 件的阶梯价 ← 此价会写入 PI
- 大货周期

另请提供：出口报关单（近一年，看抬头）、开模/打样记录。方便的话约视频验厂。
```

### SKU-B｜威海渔具厂（木虾/egi）

```
老板您好，我做澳洲市场跨境电商，找有对日出口记录的木虾工厂长期合作。

产品：木虾套装（2.5/3.0/3.5 混号，5 只装）+ 配套网眼排水收纳包
规格要求（请逐条确认）：
1. 伞钩必须不锈钢（会做 48 小时盐水浸泡测试）
2. 配重用锡，不用铅
3. 布面 UV + 夜光
4. 沉姿要求 45°，每批出厂做泡水校准，实测沉速要能标到包装上
   （对标：2.5 号 10.5g 约 5.0s/m，3.0 号 15g 约 3.5s/m，3.5 号 20g 约 3.0s/m）
5. swim-test（直游不旋转、拖环不歪）写入质检单

请报：
- 样品费用与周期（每个号 3–5 只）
- 首批 500–1000 只的单价梯度
- 排水收纳包（网眼+EVA 钩冠护套）能否配套做，或介绍配套厂
- 返单价 ← 会写入 PI

另请提供：对日出口报关单（日单=沉速品控过关的硬证明）。可约视频验厂。
```

## 2. 验厂三件套核查（防「工厂型贸易商」）

| 项 | 看什么 | 红旗信号 |
|---|---|---|
| ① 出口报关单 | **抬头是否本厂**；近一年出口目的国与品类 | 抬头是外贸公司；只给截图不给原件扫描 |
| ② 开模/打样记录 | 有无自有版房/样品间；打样是否本厂完成 | 「样品要一周以上」（大概率外发）|
| ③ 视频验厂 | 直播走一遍缝纫线/装配线；看在产订单 | 只肯拍空车间/成品间；回避产线实拍 |

三项全过才进入打样。任何一项含糊 = 中间商，直接淘汰（多付 10–20% 差价还丢品控主导权）。

## 3. PI（形式发票）必备条款清单

- [ ] **返单价条款**：首批 ___ 件单价 ¥___；6 个月内返单 ___ 件内单价不高于 ¥___
- [ ] 材料规格入合同：面料克重 / 扣具材质金属 / YKK / 不锈钢伞钩 / 锡配重（写型号，不写「同等品质」）
- [ ] 批检条款：每批 10% 抽检，检项见 §5；不合格率 >3% 整批可拒收或返工
- [ ] 交期与逾期条款：大货 ___ 天；每逾期一周扣货款 __%
- [ ] 付款节奏：30% 定金 / 70% 验货合格后付（首单不做全款前置）
- [ ] 包装要求：中性包装 + 我方标签；SKU-B 沉速标注由厂方按批实测值印贴
- [ ] 模具/版权归属：专用版型纸样归我方，厂方不得外卖同版型

## 4. G2 样品测试协议（记录表随测随填）

### SKU-A 样测（收样 48h 内完成）

| # | 测试 | 方法 | 通过线 | 结果 |
|---|---|---|---|---|
| 1 | 上车安装 | Hilux N80 / Ranger 后排实装（无车则按尺寸图硬纸板模拟）| 版型贴合、绑带够长、不挡杯架 | |
| 2 | 扣具暴力测试 | 单点悬挂 10kg 水桶 24h；反复开合 200 次 | 无断裂无变形无滑扣 | |
| 3 | 缝线检查 | 数针距（卡尺）；拉扯受力缝合处 | 针距 ≤3mm，双针，无跳线 | |
| 4 | 面料克重 | 剪 10×10cm 称重 ×100 | 与标称偏差 ≤5% | |
| 5 | 泼水测试 | 500ml 水淋表面 | 内侧不渗（water-resistant 口径）| |

### SKU-B 样测（收样 72h 内完成）

| # | 测试 | 方法 | 通过线 | 结果 |
|---|---|---|---|---|
| 1 | 沉姿角度 | 透明水桶/浴缸泡水观察 | 45°±5°，头下尾上不倒栽 | |
| 2 | 沉速实测 | 1m 水深计时 ×3 次取均值 | 与厂标偏差 ≤10% | |
| 3 | 直游测试 | 水中匀速拖动 | 不旋转、不侧翻、拖环不歪 | |
| 4 | 盐水浸泡 | 食盐水（35g/L）浸 48h 后晾干 | 伞钩无锈点、布面无脱胶 | |
| 5 | 结构强度 | 伞钩逐根掰压；布面撕拉 | 钩不断不弯，布面不起层 | |

**G2 判定**：两 SKU 全项通过 → 首批下单（A 150 件 / B 500–1000 只）；
任一项不过 → 反馈工厂改样重测，**改样两轮仍不过 = 换厂**（沉没成本止损）。

## 5. 首批批检 SOP（写入 PI 附件）

抽检 10%（A：15 件 / B：50–100 只），检项：
- SKU-A：扣具材质（磁铁验金属）+ 开合 20 次；针距抽 3 处；标签克重印刷
- SKU-B：每批随机 10 只泡水沉姿 + 沉速；伞钩目检锈点；包装沉速贴与实测一致
- 记录留存：批检照片/视频归档到 `data/private/qc/<批次号>/`（周报归因用）
